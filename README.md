# PJFAutoImport

Landing page estática para GitHub Pages, desarrollada con HTML, CSS y JavaScript puro.

## Estructura

- `index.html`
- `styles.css`
- `script.js`
- `assets/logo-pjfautoimport.png`

## Formspree

1. Crea una cuenta y un formulario en Formspree.
2. Configura el correo de destino como `pjfautoimport@gmail.com` y verifica la dirección.
3. Copia el endpoint asignado, con formato `https://formspree.io/f/XXXXXXXX`.
4. Sustituye `https://formspree.io/f/ID_DEL_FORMULARIO` en `script.js`.
5. Realiza un envío de prueba desde la web publicada.

## GitHub Pages

1. Crea un repositorio, por ejemplo `pjfautoimport`.
2. Sube todos los archivos manteniendo la estructura.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique la URL.

## Antes de publicar

Reemplaza los placeholders de URL pública en `index.html`, configura Formspree y completa/revisa legalmente los datos de privacidad y aviso legal.
